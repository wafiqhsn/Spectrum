# Contributing

Bug reports and feature suggestions are welcome through GitHub Issues. Include the macOS version, app build, visualizer style, output device type, and steps to reproduce. Redact personal paths, account details, and any sensitive diagnostics.

Before submitting a change, build the Spectrum scheme and run `bash Tests/run.sh`. Explain the behavior change and any manual checks, particularly for audio capture and window lifecycle behavior.

No source license has been selected yet. Clarify contribution and licensing expectations with the maintainer before submitting substantial code or artwork.
